# AI Life OS｜内心圆桌 商业计划书

> 定位：一个围绕用户长期成长建立的 AI 内心支持系统
> 版本：v1.0 · 2026-08
> 方法论：Wharton 风格——先问题与市场，再产品与单位经济，最后风险与里程碑

---

## 一、执行摘要（Executive Summary）

AI Life OS 是一个多角色 AI 陪伴与人生决策支持系统。用户不是和一个聊天机器人对话，而是进入一个由多个 AI 陪伴人格组成的「内心圆桌」：温柔的母亲提供接纳、理性的导师提供框架、知心朋友提供陪伴、内在小孩说出压抑的情绪、未来的自己提供长期视角——系统根据用户当下的情绪与需求，动态判断谁来回应。

当前产品已完成可交互原型（React + DeepSeek）：人格档案、内心圆桌、多维未来模拟器、人格网络（Agent 社区雏形）四大模块，全部本地可用。

**本计划回答三个问题**：
1. 谁会为它付费？（两群人：被决策焦虑困扰的年轻人；担心父母孤独的子女）
2. 凭什么是它？（差异不在"聊天"，而在「人格会随使用进化」+「从情绪支持到行动决策的完整闭环」）
3. 怎么赚钱？（免费体验 + 订阅 + 圆桌深度会话 + 技能/服务交换市场）

## 二、问题（Problem）

### 2.1 两个真实且被低估的痛点

**A. 年轻人的「决策孤独」**
20-35 岁的城市年轻人面临高频人生决策：换城市、转行、考研还是工作、要不要创业。传统支持系统（父母、朋友）要么利益相关、要么缺乏相关经验；心理咨询按次 300-800 元、周期以月计，对"每周都会冒出来的具体纠结"太重。结果是：他们用 AI 聊天 App 倾诉，但通用聊天机器人给的是"正确的废话"，聊完问题还在。

**B. 老人的「情感空巢」**
中国 60 岁以上人口约 3 亿，其中独居/空巢家庭规模过亿。老人的核心问题不是"没人说话"，而是：
- 没有人**耐心听**他们说小事（子女忙、听不懂、嫌唠叨）
- 没有人**记得**他们说过什么（"上礼拜我跟你说过的那件事"）
- 不敢麻烦子女（"孩子工作忙，我不想让他担心"）

### 2.2 对现有方案的失败分析

| 现有方案 | 为什么不够 |
|---|---|
| 通用 AI 聊天（ChatGPT 类） | 无记忆连续性、无人格差异、每句话都像新对话 |
| AI 陪伴 App（星野/C.ai 类） | 娱乐向角色扮演，不沉淀成长，不解决决策 |
| 传统心理咨询 | 贵、重、有病耻感，无法覆盖"今天中午吃什么"级别的日常 |
| 子女的电话关心 | 频率低、耐心有限、话题绕不开"吃了没" |

## 三、目标用户与付费意愿（诚实评估）

### 3.1 人群一：决策焦虑的年轻人（首发市场）

**画像**：22-35 岁，一线城市或新一线，大学以上学历，日常使用 AI 工具。
**他们会付费吗？——会，但有条件。**

诚实评估我们当前产品的付费说服力：
- ✅ 有独特体验：圆桌多角色动态讨论、未来多维模拟、"来宾专家"给把脉——这些截图有分享传播力
- ✅ 对标付费习惯：这个人群已在为 ChatGPT Plus（$20/月）、星野会员、知识付费付费
- ⚠️ 但前提是：AI 回复必须是**真 AI**（当前静态部署版只有本地模板引擎，回复质量撑不起付费）
- ⚠️ 付费的最终理由不是功能列表，而是「它记得我，而且它真的帮我做成了决定」

**定价测试建议**：免费 3 次圆桌深度会话/月 → 订阅 ¥19/月（无限会话+长期记忆+决策空间）→ 年费 ¥168。低于一杯咖啡+一顿外卖的心理门槛。

### 3.2 人群二：老人与「代付的子女」（第二曲线，需要专门产品）

**诚实的结论：当前版本不适合不识字的老人直接使用。** 差距是硬性的：
- 核心交互依赖打字；老人不识字/不擅长拼音就无法使用
- 深色背景、小字、像素风、"圆桌/MBTI/模拟器"等抽象概念，都是年轻人的审美语言
- 数据存在浏览器、需要理解"体验 Demo"流程——老人操作不了

**但这恰恰是更值钱的市场**，前提是做「适老化语音版」而不是直接移植：
- 交互 = 说话（语音识别）+ 听（语音播报），**零文字、零打字**
- 界面 = 一个大头像 + 一句话回答，没有菜单
- 内容 = 不聊"MBTI/成长"，聊"今天吃了什么""孙子多大了""当年在厂里的事"——AI 记得他们说过的一切
- **付费者往往是子女**：月费 ¥20-50 的"AI 陪伴父母"套餐，对比父母在保健品/电视购物上的月消费数千元，这是一笔子女愿意付的"安心费"。产品的情感钩子是子女端的「爸妈今天聊了什么」情绪日报——缓解的是子女的愧疚感

**一句话**：年轻人版卖「决策支持」，老人版卖「安心」，子女付费。同一个内核，两个外壳。

### 3.3 传播性判断（"我朋友看到了会不会也想要"）

产品的天然传播点不是广告，而是**对话截图**：
> 用户：我创业失败了，爸妈一直说当初就不该让我创业。
> 🌙 母亲：你是不是其实最难受的，不只是创业失败，而是你最希望得到理解的人，却没有站在你这边？

这种"被说中"的瞬间具备社交货币属性。冷启动策略应围绕"让用户体验一次高质量圆桌 → 引导截图分享"设计，而非投放。

## 四、产品（Product）

### 4.1 已完成（当前原型）
- **人格档案**：随使用进化的动态人格（能力维度、成长轨迹、AI 观察依据，用户可确认/删除）
- **内心圆桌**：5 位陪伴角色（母亲/导师/朋友/内在小孩/未来的自己）+ 动态发言机制 + 多选/全员讨论 + 灯光聚焦 + 像素小人视觉
- **来宾系统**：从社区邀请外部 Agent 坐进圆桌共同讨论（老莫：创业导师；沈知微：心理咨询师……各有 MBTI 与专长）
- **未来模拟器**：一个选择 → 多条人生路线 × 10 维变化 × 关键事件剧情 × 三种未来 × 风险闭环 × 30/90 天行动
- **日常助手**：日常小选择一步到位拍板

### 4.2 差异化（为什么不是"又一个 AI 聊天"）
1. **人格进化**：AI 对用户的理解随使用加深，形成档案（有来源、置信度、用户确认）
2. **多视角而非单点**：同一个问题，母亲/导师/朋友/未来的自己给出不同立场
3. **从情绪到行动的闭环**：情绪 → 理解 → 认知 → 决策空间 → 30/90 天行动
4. **记忆即关系**：每个角色记得与你有关的不同侧面（导师记得你的模式，母亲记得你的疲惫）

### 4.3 路线图
- Phase 1（已完成）：原型四模块 + DeepSeek 接入 + GitHub Pages 部署
- Phase 2（下一步）：语音适老版（零文字交互）+ 后端代理（真 AI 上线）+ 订阅支付
- Phase 3：真实多用户社区（Agent 上架）+ 子女端小程序（父母情绪日报）+ 技能交换市场

## 五、商业模式（Business Model）

| 收入线 | 形式 | 定价假设 | 目标人群 |
|---|---|---|---|
| 免费层 | 每月 3 次圆桌会话、本地记忆 | ¥0 | 获客与传播 |
| 订阅 | 无限圆桌 + 长期记忆 + 情绪曲线 + 决策空间 | ¥19/月 或 ¥168/年 | 年轻主力 |
| 家庭陪伴套餐 | 适老语音版（父母端）+ 子女端日报 | ¥29/月 或 ¥258/年 | 子女代付 |
| 圆桌专家会话 | 单次深度会话（导师模式/模拟器联动） | ¥9.9/次 | 低频高价值 |
| 技能交换市场 | 社区 Agent 技能服务撮合抽成 | 交易额 10-15% | 远期 |

**成本结构**：LLM 推理为主（DeepSeek 单次会话成本约 ¥0.01-0.05，月活用户成本远低于 ¥19 定价，毛利率 85%+）；无库存、轻运营。

## 六、市场与竞争（Market & Competition）

**市场量级（公开口径的量级估计，非精确预测）**：
- 中国 60+ 人口约 3 亿，空巢/独居家庭过亿 → 银发情感陪伴是万亿级银发经济的高频入口
- AI 陪伴类应用已验证需求（星野、Character.ai 等产品的用户规模与付费）
- 数字心理健康服务年增速快，但供给以 B 端企业服务为主，C 端日常陪伴空缺

**竞争定位**：
| 竞品 | 它是什么 | 我们的差异 |
|---|---|---|
| 星野 / Character.ai | 娱乐向角色扮演 | 我们沉淀成长与决策，角色服务于用户而非剧情 |
| ChatGPT 类通用助手 | 万能但无记忆人格 | 多角色立场 + 长期记忆 + 进化档案 |
| 心理咨询平台 | 重、贵、病耻感 | 覆盖日常轻度需求，明确定位为陪伴非治疗 |
| 适老机器人/音箱 | 功能型（提醒吃药） | 情感记忆连续性——记得 TA 说过的每一件事 |

## 七、风险（Risks——诚实列出）

1. **情感依赖与伦理风险**（最高优先级）：AI 陪伴可能造成过度依赖。对策：产品内建边界（不替代真实关系、危机信号转介专业援助、陪伴时长提醒）——这既是责任也是监管必需。
2. **监管**：AI 生成内容备案、心理类表述边界、老年人个人信息保护。对策：明确定位"陪伴与思考工具非治疗"、生成内容合规审查、隐私本地优先。
3. **大厂竞争**：星野/字节等随时可加同款功能。对策：护城河不在单点功能，在「档案进化 + 记忆 + 关系」的长期数据资产与适老垂直场景（大厂不愿做的重运营）。
4. **模型成本波动**：推理成本随规模上升。对策：分级模型策略（日常用低价模型，深度会话用推理模型），毛利率已预留空间。
5. **冷启动内容质量**：AI 回复质量是生死线。对策：人格 prompt 持续调优 + 用户反馈闭环 + 关键场景人工审校。

## 九、The Ask

当前阶段不需要大额融资——产品验证成本极低（单人 + API 费）。需要的是：
1. **20 个种子用户**（10 个年轻人做付费意愿测试，5 组家庭做适老版实测）
2. 一笔小额启动资金（¥3-5 万）覆盖：云服务 + 支付/备案合规 + 适老语音方案外包
3. 一位有医疗/养老资源或渠道的顾问

验证 M1-M3 后，再以数据谈天使轮。
