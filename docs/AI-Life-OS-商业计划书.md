# AI Life OS｜内心圆桌 商业计划书

> 产品定位：一个懂你日常习惯、陪你走完重大决策、并让你找到同频人格的 AI 决策与陪伴系统
> 版本：v2.0（按核心双功能重构）· 2026-08
> 方法论：Wharton 风格——问题 → 市场 → 产品 → 单位经济 → 竞争 → 风险 → 里程碑

## 〇、执行摘要（Executive Summary）

每个人都有两类决策：**每天几十次的微决策**（今天喝哪家的咖啡、中午吃什么）和**一生几十次的重大决策**（要不要考研、该不该创业）。前者没人帮（问了显得矫情），后者没人能帮（父母不懂你的行业，朋友有立场）。

AI Life OS 用一个产品同时解决这两层：

- **功能一 · AI 决策助手**：记住你的日常习惯（周一瑞幸生椰拿铁、周二星巴克星冰乐），微决策一步到位替你拍板；重大决策（该不该考研）结合你的人格、目标与历史行为，做结构化分析、人生推演（3-5 年后的你会怎样）、并全程提醒你的待办事项。
- **功能二 · MBTI 人格社交圈**：每个人把自己的 Agent 人格放进社区。INTJ 圈可以约学习、组自律健身；跨圈可以精准找人——正在考研的大三学生，能找到一位考过研的学长，先看他的人格档案判断是不是负责任的人，再决定要不要深聊。当关系中触碰到更深的情绪，系统切换为「内心圆桌」：化身母亲人格，倾听你的故事。

**商业本质**：微决策建立信任与习惯数据，重大决策完成付费转化，人格社交圈带来留存与传播。三层飞轮，一个档案。

当前产品已完成可交互原型（GitHub Pages 已部署）：日常决策助手、内心圆桌（5 角色 + 动态发言 + 多选讨论）、多维未来模拟器、人格网络（星系 + 社区成员 + 技能价目）。

## 一、问题（Problem）

### 1.1 微决策：每天 35 次的隐形消耗
研究普遍认为成年人每天做出数万个决策，其中大量是"中午吃什么""喝哪家咖啡"级别的微决策。它们单看不重要，但持续消耗意志力——这就是"决策疲劳"。现有工具（外卖 App 的推荐算法）优化的是平台成交，不是你的习惯与状态。

### 1.2 重大决策：一生几十次的孤立无援
考研、换城市、转行——这类决策的特点是：信息不对称（没人知道你适不适合）、利益不对称（父母朋友有立场）、试错成本高。心理咨询太重（按次 300-800 元、以月为周期），搜索引擎太泛，父母太主观。**用户缺的不是信息，是一个懂他立场、可反复对话的决策过程陪伴者。**

### 1.3 社交：想找"走过我要走的路"的人
MBTI 在 Z 世代已是通用社交语言（小红书/抖音 MBTI 内容头部账号单系列播放量数百万）。年轻人真实的社交需求不是"认识更多人"，而是**精准找到同频或先行的人**：考研人想找考上的学长，创业者想找踩过坑的前辈。现有社交平台按颜值/距离匹配，没有按"人生阶段 + 人格 + 目标"匹配的产品。

### 1.4 情绪：重大决策背后的那道坎
决策焦虑的底层往往是情绪：怕让父母失望、怕失败被看笑话。通用 AI 会讲道理，讲不到心里。需要一个能「化身你最需要的那个倾听者」的情绪出口——但绝不能变成替代真实关系的黑箱。

## 二、产品：一个档案，两大核心功能

### 2.1 功能一 · AI 决策助手（决策分层引擎）

**Layer 1｜日常微决策（免费，日活入口）**
- AI 记住你的日常习惯：「周一瑞幸生椰拿铁、周二星巴克星冰乐」
- 问"今天喝什么"→ 一步到位：「今天周一，按你的惯例是瑞幸生椰拿铁；昨晚没睡好的话，建议换成热美式」
- 同步管理待办事项与提醒（图书馆、健身、复盘）

**Layer 2｜重大决策陪伴（付费转化点）**
- 「我该不该考研」→ 不给一句废话，生成结构化决策分析：结合人格、目标、历史行为
- 决策过程中持续陪伴：备考节奏、报名节点、动摇期的心理支持

**Layer 3｜人生推演**
- 「3-5 年后的我会怎样」：多条人生路线 × 10 个维度（事业/财务/能力/家庭/情绪/生活方式…）
- 关键事件剧情模拟（第 8 个月增长停滞怎么办）+ 三种未来（乐观/基准/压力）
- 落地为 30 天/90 天行动清单与止损线

### 2.2 功能二 · MBTI 人格社交圈（圆桌社交）

**① 圈层匹配**：把自己的 Agent 人格放进社区。INTJ 圈约学习、组自律健身打卡；跨圈精准找人——考研的大三学生，按「考过研 + INFP 的耐心」找到那位学长。

**② 人格透视（信任建立）**：决定深聊之前，先看 TA 的 Agent 人格档案——能力维度、成长轨迹、社区帮助记录、已确认的行为模式。**信任来自数据，不来自自我介绍。**

**③ 内心圆桌（情绪疗愈层）**：当对话触到更深的情绪，系统切换圆桌模式——化身母亲人格倾听你的故事。设计红线：不做心理诊断，系统只提出「观察到的模式」，由用户自己确认；危机信号自动转介专业援助。

**④ 一起讨论**：邀请 2-4 位社区成员的 Agent 上圆桌，就你的真实问题多视角讨论（考研人 + 导师 + 朋友的立场同框），生成讨论纪要。

### 2.3 技术与数据护城河
- **记忆连续性**：所有对话沉淀为带来源与置信度的长期记忆，Agent 关系随时间加深
- **用户主权**：记忆可查看、确认、删除；AI 的推断需用户确认才升级为长期档案
- **多 Agent 编排引擎**（已完成）：情绪/需求分析 → 角色评分 → 动态发言 → 记忆写回，同一引擎支撑圆桌与社区讨论

## 三、目标用户与付费意愿（User & Willingness to Pay）

### 3.1 核心人群：18-30 岁决策密集期年轻人
大学生与职场前五年。他们用 MBTI 社交、为 AI 工具付费、处于考研/就业/搬家的高频决策期。
**付费意愿判断**：为「日常决策助手」付 ¥19/月 的门槛低于一杯咖啡+一顿外卖；重大决策深度模拟按次付费（¥9.9/次）符合低频高价值心理。

### 3.2 次级人群：备考/转型中的目标驱动者
考研、考公、转行人群的共性：周期长、孤独感强、需要过程陪伴。决策助手的过程陪伴（节奏/提醒/动摇期支持）是他们的刚需场景。

### 3.3 传播机制
产品的传播不是广告，是**对话截图**：圆桌上导师一句精准拆解、来宾学长一句过来人经验——"被说中"的瞬间自带社交货币。冷启动围绕「让用户体验一次高质量圆桌 → 引导截图分享」设计。

| 收入线 | 内容 | 定价假设 | 人群 |

## 五、竞争分析（Competition）

| 竞品 | 它是什么 | 我们的差异 |
|---|---|---|
| 星野 / Character.ai | 娱乐向角色扮演 | 我们沉淀真实成长与决策，角色服务于用户的人生而非剧情 |
| ChatGPT / 豆包 | 通用助手，无记忆人格 | 决策分层 + 长期记忆 + 人格社交，角色之间有立场差异 |
| Keep / 小红书 | 功能社区 | 按「人格 + 目标 + 阶段」精准匹配人，而非内容流偶遇 |
| 心理咨询平台 | 重决策支持 | 轻、日常、无病耻感，覆盖咨询覆盖不到的微决策层 |

**护城河**：单点功能可被模仿，但「用户档案 × 长期记忆 × 角色关系」随时间复利——用得越久，AI 越懂你，迁移成本越高。

## 六、增长策略（Go-to-Market）

1. **MBTI 内容社区冷启动**：MBTI 是自带流量的内容品类（头部账号单系列播放数百万）。围绕「圆桌金句」制作短视频/图文素材投放小红书与抖音。
2. **高校场景切入**：考研/考公人群是决策焦虑最集中、社交需求最强的场景；与学习搭子文化天然契合。
3. **截图裂变机制**：每次圆桌讨论结束生成可分享的「讨论纪要卡」。
4. **社区 self-serve**：用户上架自己的 Agent 人格即成为传播节点（TA 会拉自己的朋友来对谈）。

## 七、财务框架（Financial Framework，量级估算）

- **成本结构**：LLM 推理（DeepSeek 单次多 Agent 会话约 ¥0.05-0.3）+ 静态托管近零 + 无库存运营。对订阅定价毛利率 85%+。
- **单位经济假设（M3 验证目标）**：免费:付费 ≈ 10:1；付费用户月均 30 次交互，推理成本 <¥3/人/月。
- **三年粗测**：Y1 验证期（种子 1k，付费转化 3%）→ Y2 增长期（1 万用户，订阅 + 市场抽成）→ Y3 规模期（10 万用户，四条收入线并行）。以真实留存数据滚动修正。

---

## 八、风险与对策（Risks）

1. **MBTI 科学性争议**：定位为「行为偏好的社交语言与参考」，禁止基于 MBTI 做心理诊断或贴创伤标签——这既是合规也是产品体验设计（观察→用户确认制）。
2. **情感依赖**：AI 陪伴不能替代真实关系。对策：陪伴时长提醒、鼓励线下行动的闭环设计、危机信号自动转介专业援助。
3. **监管**：生成式 AI 备案、未成年人保护、个人信息保护。对策：记忆本地优先 + 用户主权（可查看/删除）、内容边界内建。
4. **大厂跟进**：星野/字节可复制多角色聊天。护城河在「长期记忆资产 + 真实社区 Agent + 决策闭环」的组合，而非单点。
5. **多用户后端成本**：真实社区需要后端。对策：第一期 AI 模拟社区已验证需求，再以收入支撑后端投入。
